# 原文提取：Towards org-level agent harnesses

来源链接：https://x.com/RLanceMartin/status/2070571422913876182

作者：Lance Martin

发布时间：2026-06-26

主题：组织级 agent harness 如何改变企业内部使用 AI agent 的方式。

## 原文核心结构

1. Claude Tag 在 Anthropic 内部快速增长，原因不只是模型能力变强，而是 agent UX 从个人工具变成组织级 harness。
2. 从 single-player 到 multi-player：过去每个人有自己的 Claude Code harness 和个人 connector；现在 Claude Tag 在 Slack 中提供组织级 agent identity、connector 和 skill。
3. 组织级 harness 带来几个收益：
   - 新员工可以立即使用和其他人一样的 harness，降低 onboarding 成本。
   - 共享上下文和安全边界让 Claude 能看见公共频道中的相关信息，减少重复劳动，扩散最佳实践。
   - 让多人协作变得自然，比如事故排查、长讨论自动整理 postmortem。
4. 从 synchronous 到 asynchronous：过去 Slackbot 需要频繁 check-in、推动、审批；当模型能做更长周期任务，产品界面也应从实时对话变成异步委托。
5. 异步体验的成立依赖：
   - 模型能力提升。
   - prompt injection 抵抗力提升。
   - classifiers/auto-mode 能审查 action。
   - Claude Tag 有更强的安全模型。
   - goal 等 primitive 让 Claude 可以运行、衡量目标、纠偏。
6. 长周期任务也适合用 HTML dashboard 和可视化作为沟通界面。
7. 从 reactive 到 proactive：异步 agent 不能只等人来问，它需要在卡住、达到条件、或发现相关信息时主动提醒。
8. 主动性的偏好因任务、用户、频道而不同。Claude Tag 通过 channel-based memory 记录偏好。
9. 作者列出三类主动场景：
   - 实验监控：Claude 监控长实验并主动协助保持运行。
   - 主动搜索：Claude 在开始任务前搜索频道，找已有工作和最佳实践。
   - Channel watcher：告诉 Claude 在某个条件满足时 ping 自己。
10. 结论：Claude Tag 应被看作组织级 agent harness，Slack 只是第一个 surface。它由长周期任务能力和安全改进共同推动，并解锁多人、异步、主动三类新交互模式；它也和 CLI 等 Claude Code surface 互补。
