## Target Audience

- **Primary**: 对 AI 提效感兴趣的职场人、产品经理、程序员、自媒体创作者
- **Secondary**: 设计、教育、电商、运营、HR、财务等非技术岗位
- **Need**: 不想研究复杂概念，希望快速知道“我的职业该配哪些 Skill”

## Hook Analysis

**标题钩子评分**: ⭐⭐⭐⭐⭐

- 身份与痛点钩子：“你的职业”降低理解门槛
- 反常识钩子：“别再只装聊天软件”强调 Skill 与普通 AI 工具的差异
- 利益钩子：直接得到职业专属装机单

## Value Proposition

1. 20 个行业、93 个岗位，覆盖面广
2. 3 题生成 5 必装、5 进阶、3 个能力建议
3. Skill 来自真实 GitHub 项目并保留核验版本
4. 离线本地运行，无需登录

## Engagement Design

- 收藏触发：职业 AI Skill 清单可反复查看
- 分享触发：转给同岗位同事测试
- 评论问题：你的岗位最想让 AI 帮你解决哪件事？

## Visual Opportunity Map

- 封面：职业扫描仪、Skill 芯片、强标题
- 产品机制：行业→岗位→3题→装机单流程
- 结果结构：5+5+3 数字大字报
- 覆盖范围：20 行业、93 岗位的职业矩阵
- 结尾：输入职业、生成装机单的 CTA
