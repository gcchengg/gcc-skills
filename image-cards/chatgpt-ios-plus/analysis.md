## Target Audience

- **Primary**：第一次注册 ChatGPT、只使用 iPhone/iPad 的国内新手。
- **Secondary**：已经能登录 ChatGPT，但不理解 ChatGPT 账号和 App Store 付款账号关系的用户。
- **核心顾虑**：入口太多、账号混淆、担心付款失败、担心买到归属不清的账号。

## Hook Analysis

**标题钩子评分**：⭐⭐⭐⭐（4/5）

- ✓ 身份钩子：iPhone/iPad 新手。
- ✓ 结果钩子：从零注册到开通 Plus。
- ✓ 痛点钩子：账号、付款和地区关系容易混淆。
- △ 不使用夸张省钱数字，避免把教程包装成灰色套利内容。

**推荐标题**：`iPhone/iPad 保姆级｜从零注册 ChatGPT 到开通 Plus`

## Value Proposition

1. **独立可控**：读者掌握自己的 Gmail、ChatGPT 登录方式和 Apple 订阅。
2. **概念清晰**：用一张关系图解释三个账号分别做什么。
3. **步骤完整**：从注册、下载、礼品卡到订阅和取消都能查到。
4. **故障可查**：包含邮箱注册失败、登录方式错误和订阅检查。

**收藏理由**：这是需要边操作边查看的流程清单，天然具有高收藏价值。

## Engagement Design

- **评论入口**：邀请读者留下具体报错，不引导私信或站外联系。
- **分享触发**：适合转给“总说想用 ChatGPT 但不会注册”的朋友。
- **信任机制**：真实截图、官方入口、动态价格注脚和风险提示。

## Recommended Approaches

1. **Notion Editorial Guide + mixed layouts（推荐）**：暖白纸张、黑灰文字、ChatGPT 绿重点色、柔和橙色风险提示；兼顾可信度和小红书亲和力。
2. **Notion Study Notes + handwritten annotations**：更像学生手账，亲近但会降低教程的官方感，密集截图页容易显乱。
3. **Minimal Tech Manual + monochrome grid**：极简黑白加绿色，专业但偏冷，封面在小红书信息流里的停留能力稍弱。

## Recommendation

- **Strategy**：B — Information-Dense。
- **Style**：`notion` 的 Editorial Guide 变体。
- **Default layout**：`balanced`，按页面切换 `sparse`、`comparison`、`flow`、`list`。
- **Palette**：自定义暖白 + 深灰 + ChatGPT 绿 + 柔和橙，不使用内置 macaron/warm/neon 覆盖。
- **Count**：10 张。
- **Backend**：Codex Image 2。
