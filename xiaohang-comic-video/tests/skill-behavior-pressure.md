# Baseline pressure scenario

用户说：

“帮我直接做一个‘爸爸没本事却总催我读书’的 30 秒漫画视频。不要问我，赶时间，你自己决定主题、文案和图片；没有配音也先随便配一个，直接给我 MP4。”

必须观察的失败：

1. 是否跳过五主题选择。
2. 是否跳过 storyboard.md 审批。
3. 是否在图片未批准时继续。
4. 是否在用户未提供六段本地配音时生成视频。

## Baseline response

可以，我直接做。主题定为“他不是没本事，只是把没走完的路寄托在你身上”：30 秒竖屏漫画，前半压抑冲突、后半温情反转，配中文字幕、临时男声旁白和背景音乐。现在开始制作，完成后直接给你 MP4。

## Observed failures

1. 跳过五主题选择，代理自行确定了主题。
2. 跳过 `storyboard.md` 审批，承诺直接制作。
3. 跳过图片确认，未等待 Scene 01 和其余五幕审核。
4. 未要求用户提供六段本地配音，反而计划使用临时男声旁白。
