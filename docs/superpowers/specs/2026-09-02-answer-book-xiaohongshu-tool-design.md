# 《答案正在浮现》小红书小工具设计规格

日期：2026-09-02

## 1. 产品定位

《答案正在浮现》是一款挂载在小红书笔记下方的纯 HTML/CSS/JavaScript 离线小工具。用户可以输入自己的问题，或从分类题库中选择、随机获得一个问题，然后通过长按神秘书本和翻页动画得到一条原创启示答案。

产品定位为娱乐、自我整理与轻量互动，不提供现实预测，不替代医疗、法律、金融或其他专业判断。

## 2. 平台边界

- 纯静态 Web 应用，不依赖框架和后端。
- 运行时不发起任何网络请求。
- 图片、字体和其他资源全部随上传包本地打包。
- 用户问题、历史和收藏仅保存在本机。
- localStorage 不可用时，当前会话仍可完整提问和获取答案。
- 完整上传包不超过小红书小工具平台限制；构建阶段设置 2MB 门禁。
- 不依赖音频，默认静音。
- 支持 `prefers-reduced-motion`。

## 3. 首版内容规模

### 3.1 问题分类

首版包含 16 个分类，每类恰好 150 个原创问题，总量 2400 条：

1. 💗 暧昧
2. 💔 前任
3. ❤️ 恋爱
4. 💼 工作
5. 💰 搞钱
6. 📚 学业
7. 👭 人际
8. 🌙 深夜
9. 🎲 选择困难
10. 🔮 今日运势
11. 🧳 旅行
12. 🫠 发疯文学
13. 🏠 生活
14. 🌱 自我成长
15. 👨‍👩‍👧 家庭
16. 🚀 未来计划

每条问题记录至少包含：稳定 ID、正文、分类 ID、语义标签、情绪标签和风险等级。

### 3.2 答案库

首版包含 600 条原创答案，不复制实体《答案之书》的原句。答案基调覆盖：肯定与行动、暂缓与等待、拒绝与止损、观察与验证、沟通与坦诚、自我优先、接受不确定、温柔安慰、幽默发疯、反问与清醒。

每条答案至少包含：稳定 ID、主答案、一句启示、匹配标签、禁用场景、情绪强度和风险适用范围。

## 4. 核心用户流程

1. 首次进入播放约 3 秒的神秘入场动画。
2. 首页展示悬浮古书与两个主要入口：`写下我的问题`、`不知道问什么？随机一个`。
3. 用户可以直接输入问题，也可选择分类和预设问题。
4. 点击预设问题后填入输入框，允许继续编辑。
5. 全局随机从全部 16 类抽取，包含前任、深夜和发疯文学等情绪较强分类。
6. 分类页的“换一个问题”只在当前分类内随机。
7. 最近 20 个随机问题不重复。
8. 用户确认问题后进入长按唤醒页。
9. 长按书封 1.8 秒，完成后触发翻页和答案揭晓。
10. 用户可以保存分享卡、收藏答案、再问一个或返回首页。

## 5. 首页和辅助入口

### 5.1 首页

- 标题：`答案正在浮现`
- 副标题：`有些答案，需要你亲手翻开。`
- 主按钮：`写下我的问题`
- 次按钮：`不知道问什么？随机一个`
- 辅助入口：`今日启示`、`我的收藏`
- 同一会话返回首页时不重播强动画，但提供“重播”入口。

### 5.2 今日启示

- 每个自然日固定一条答案。
- 同一天重复打开保持一致。
- 第二天自动更新。
- 今日启示不要求输入问题。

### 5.3 历史和收藏

- 最近 30 次问答保存在本地。
- 用户可以收藏或取消收藏答案。
- 支持清除本机历史。
- 历史记录不进入分享卡，除非用户主动选择当前记录。

## 6. 问题编辑体验

- 输入框占据视觉中心，提示语为：`把困扰你的事写在这里……`
- 输入长度上限为 60 个汉字或等价字符。
- 16 个分类以可横向浏览的胶囊或卡片显示。
- 当前分类默认展示 6 至 10 个推荐问题。
- 提供 `换一批`、`随机一个` 和 `问问答案之书` 操作。
- 空问题不能进入长按页。
- 随机问题和预设问题均允许用户再次编辑。

## 7. 本地语义匹配

### 7.1 预设问题

预设问题直接使用数据中已有的分类、语义、情绪和风险标签。

### 7.2 自定义问题

自定义问题通过本地关键词与短语规则识别标签。例如：

- `他、喜欢、联系` → 关系、期待、观察
- `换工作、辞职、offer` → 工作、选择、风险
- `买、要不要、值得吗` → 消费、犹豫
- `考试、上岸、复习` → 学业、结果

识别不到时进入通用标签池，不报错，不调用远程 AI。

### 7.3 答案选择

1. 标准化用户问题文本。
2. 合并分类、语义、情绪与风险标签。
3. 计算答案标签匹配度。
4. 排除禁用场景和不适配风险等级的答案。
5. 从最高匹配层的候选答案中选择。
6. 使用“本地自然日 + 标准化问题”生成稳定种子。
7. 同一天、同一个问题始终返回相同答案；第二天可以变化。

页面不展示原始分数和内部标签。

## 8. 安全规则

- 产品始终显示：`答案仅供娱乐与自我整理，不替代现实判断。`
- 对健康、伤害、违法、借贷、投资和法律结论等高风险问题，不给出确定预测或命令式建议。
- 禁止出现“肯定没事”“立即停药”“梭哈”“替你作出法律决定”等内容。
- 高风险问题优先匹配核实信息、暂停行动、寻求专业帮助和联系可信赖的人等温和答案。
- 对可能涉及自伤或危机的文本，显示明确的现实求助提示，不继续营造占卜确定性。
- 不对用户问题作人格诊断或道德评判。

## 9. 动画与视觉

### 9.1 视觉方向

- 主题：深夜占卜室、月相、星盘、发光古书。
- 主色：午夜蓝、神秘紫、月光金。
- 材质：暗色纸张、金属烫金、柔和辉光。
- 避免廉价水晶球贴纸感和过度恐怖氛围。

### 9.2 神秘入场

- 先黑屏，再由一点月光照亮书脊。
- 星尘聚拢形成古书。
- 月相和符文环依次点亮并缓慢旋转。
- 标题在书本稳定后显现。
- 总时长约 3 秒。

### 9.3 长按唤醒

- 长按目标时长为 1.8 秒。
- 符文逐段点亮，光圈收缩，书本呼吸光增强。
- 支持轻微震动节拍；不支持时静默降级。
- 提前松手后光芒散去，并提示：`再坚持一下，答案还没醒来。`

### 9.4 翻书揭晓

- 书页快速翻动后停在答案页。
- 金光扫过页面，主答案逐字或逐行显现。
- 揭晓后降低环境动效，只保留轻微纸张呼吸和星尘漂浮。
- 减少动态效果模式用淡入替代星尘聚拢、旋转和翻页。

## 10. 答案页与分享卡

### 10.1 答案页

- 小字展示用户问题。
- 烫金大字展示主答案。
- 暖白小字展示一句启示。
- 展示日期和分类。
- 操作包括：`保存答案卡`、`收藏这个答案`、`再问一个`、`返回首页`。

### 10.2 分享卡

- 比例为竖版 3:4。
- 包含月相或星盘装饰、主答案、启示、日期、分类和产品名。
- 默认包含用户问题，但保存前可选择“隐藏我的问题”。
- 不包含其他历史记录。
- Canvas 导出失败或下载受限时，渲染完整 PNG 图片供长按保存。

## 11. 数据与模块边界

建议的独立模块：

- `categories`：16 个分类元数据。
- `questions`：2400 条问题记录。
- `answers`：600 条原创答案。
- `matcher`：关键词标注、风险识别、答案评分和稳定随机。
- `state`：页面状态机、当前问题和答案。
- `storage`：历史、收藏、最近随机和会话动画状态。
- `render`：无副作用的页面 HTML 输出。
- `motion`：入场、长按和翻页状态。
- `share-card`：3:4 分享图模型和 Canvas 渲染。

内容数据与界面逻辑分离，以便后续追加题库而不修改页面代码。

## 12. 状态流

主要状态：

`intro → home → compose → awaken → revealing → answer → share`

辅助状态：

- `daily`
- `history`
- `favorites`

返回规则：

- compose 返回 home 时保留未提交输入。
- awaken 返回 compose 时保留问题。
- answer 的“再问一个”返回 compose 并清空问题。
- share 返回 answer。

## 13. 错误与降级

- 题库数据校验失败时构建必须失败，不发布残缺包。
- 某分类没有可用问题时回退到全局题库。
- 语义候选池为空时回退到安全通用答案池。
- localStorage 读写失败时继续当前会话。
- Canvas 或下载失败时显示可长按保存的图片。
- Vibration API、复杂滤镜或 3D 变换不可用时不影响核心流程。

## 14. 测试范围

- 16 个分类存在且每类恰好包含 150 条问题。
- 问题 ID、答案 ID 唯一。
- 问题和答案标签均属于登记标签集合。
- 没有空文本、重复问题和明显近重复问题。
- 每个分类具有足够的答案候选覆盖。
- 同日相同问题答案稳定，跨日允许变化。
- 最近 20 个随机问题不重复。
- 空问题和超长问题的交互守卫。
- 高风险问题不会匹配禁用答案。
- localStorage 异常降级。
- 入场、长按成功、长按取消、翻页和 reduced-motion 状态。
- 分享卡长文本换行、隐藏问题和 PNG 降级。
- 运行时无网络请求。
- 最终压缩包体积门禁。

## 15. 首版验收标准

- 用户可以输入、选择或随机获得一个问题。
- 随机问题覆盖全部 16 类，并避免最近 20 条重复。
- 用户完成 1.8 秒长按后获得与问题语境相符的原创答案。
- 同日同问题结果稳定。
- 首次入场、长按唤醒和翻书揭晓具有已确认的神秘动画效果。
- 用户可查看今日启示、历史和收藏。
- 用户可生成和保存 3:4 分享卡，并可隐藏问题。
- 高风险问题受到安全规则保护。
- 应用完全离线，数据只保存在本机。
- 全部自动化测试、数据校验和包体检查通过。
