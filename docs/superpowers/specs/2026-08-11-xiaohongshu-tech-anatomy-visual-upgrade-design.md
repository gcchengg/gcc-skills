# 小红书产业链解剖 Skill 视觉升级设计

## 目标

升级 `xiaohongshu-tech-anatomy`，保留历史内容中中央剖面、爆炸分层、彩色流向和工程教学图谱的账号辨识度，同时提高小红书缩略图点击力、手机可读性、场景亲和力和收藏价值。

升级不是照抄外部爆款手绘风，也不是改成平淡的企业信息图。默认视觉比例为：原有结构解剖基因约 60%，场景化/动漫手绘解释约 25%，现代编辑秩序约 15%。

## 内容与视觉模式

Skill 根据主题选择两种模式，二者共享标题、编号、色板、标注和流向语言。

### 技术硬件模式

适用于芯片、机器人、汽车三电、数据中心、设备与基础设施。

- 中央使用真实感或精致插画式爆炸剖面图。
- 外围解释核心部件、能力层、应用、成本与瓶颈。
- 保留数据流、控制流、资金流、维护反馈流等彩色线路。
- 避免把所有说明压缩为同等大小的小卡片。

### 产业生态模式

适用于演唱会、短剧、文旅、消费、平台生态与服务产业。

- 中央使用可识别的核心消费/交付场景。
- 外围使用统一画风的精致动漫人物、车辆、建筑和工作场景。
- 用路径式或环形结构表达上游、中游、下游及价值流。
- 必须解释谁创造价值、谁组织交付、谁掌握定价权、谁承担风险、谁完成变现。

## 单张海报信息架构

1. 封面级标题：优先使用问题、反常识或明确收益，不再默认使用“XX技术结构解剖图”。
2. 一句副标题：说明从什么到什么、用户能看懂什么。
3. 一个中央主视觉：第一眼必须可识别，承担主要记忆点。
4. 三至五个一级模块：围绕中央主体建立清楚阅读路径。
5. 最多四类流向：产品/服务流、资金流、数据/信息流、反馈/客流；仅保留主题需要的类型。
6. 底部一句核心判断：总结价值来源、商业权力或真实瓶颈。

## UI 质量门槛

- 3:4 竖版，默认最终尺寸 2160×2880；生成主视觉时可使用更高分辨率。
- 缩略图状态下必须看清主题和中央对象。
- 每页一个核心问题，一个主视觉，三至五个一级模块。
- 文字不得依赖 AI 图片直接生成；最终标题、标签、关系线和正文优先由 HTML/PPT/SVG 叠加，保证准确清晰。
- AI 图片主要生成无文字的中央剖面、人物、场景和局部插画。
- 使用统一人物比例、线稿、光影、材质与透视；禁止混合素材包画风。
- 保留留白和视觉节奏，但不得因极简而丢失场景、趣味和探索细节。
- 正文采用短标签与短解释；禁止大段小字和微型注释。
- 默认一个主强调色，流向色按语义固定；装饰色不超过两种。
- 输出前检查：缩略图、手机宽度、100% 放大、错字、线路遮挡、模块对齐、插画一致性。

## 生产流程

1. 读取主题进度文件，判断是否为新主题、已用主题或用户明确要求的回归测试主题。
2. 识别题型并选择技术硬件模式或产业生态模式。
3. 先确定中心命题、中央主视觉、阅读路径、流向类型和底部判断。
4. 生成无文字的视觉资产；所有关键中文由可编辑排版层完成。
5. 渲染整图并执行 UI 质量检查，不合格则针对单一问题迭代。
6. 归档提示词、可编辑源、最终 PNG 和小红书文案。

## AI 产业链验收样张

本次升级后生成一张“AI产业链”3:4 单张海报作为视觉回归测试：

- 模式：技术硬件模式为主，加入少量真实使用场景。
- 中央主体：从能源/数据中心、芯片与集群、数据与模型、工具链到应用的垂直爆炸分层系统。
- 外围说明：商业化路径、主要成本、规模化瓶颈和风险。
- 流向：算力/数据流、产品能力流、资金流。
- 标题必须具有小红书点击钩子，而不是普通报告标题。
- 画面应比历史 AI 产业链更清晰，比纯商务信息图更有视觉记忆点。

`tech-anatomy-topic-progress.json` 已将“AI产业链”记录为已使用的大模块。本次属于用户明确指定的视觉回归测试例外：允许生成，但不重复追加到 `used_big_modules` 或 `used_submodules`，不改变正常选题顺序。

## Skill 文件组织

- `SKILL.md` 保留触发条件、核心工作流、模式选择和质量门槛。
- 详细视觉规范放入 `references/visual-system.md`，仅在生成海报、轮播或 deck 时读取。
- 进度文件兼容规则放入 `references/topic-progress.md`，避免在主文件重复展开。
- 更新后运行 Skill 结构验证，并用 AI 产业链验收样张做一次实际回归检查。

## 验收标准

- 保留用户历史作品可识别的结构解剖视觉基因。
- 中央主视觉强于外围说明，缩略图不呈现均匀卡片墙。
- 有场景和探索细节，但不幼稚、不杂乱。
- 关键中文准确、清晰，不使用 AI 乱码作为最终排版。
- 用户能在三秒内看懂主题，在放大后获得值得收藏的结构信息。
