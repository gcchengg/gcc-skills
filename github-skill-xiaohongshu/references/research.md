# 选题发现与核验

## 准入门槛

- 默认分支中存在真实 `SKILL.md`，或仓库明确展示可安装的 Agent Skill 目录结构。
- `SKILL.md` 的名称、触发条件、工作方式和输出可理解；只有 Prompt 合集、MCP、普通 AI 工具或 README 宣传的不收录。
- 仓库、README、Skill 文件和许可证可访问；安装方式有可信出处。
- 能映射到至少一种具体工作任务，而非泛称“提升效率”。

## 未指定主题时

1. 搜索当天可用的 Agent Skill 榜单、GitHub 仓库和近期讨论，使用当前日期。
2. 优先近 7 天和 30 天 Star 增量或增速；再看更新时间、提交、Release、Issue/讨论活跃度。
3. 拿不到可靠历史数据时只写“近期活跃”，不得推算或编造增速。
4. 对至少 3 个候选评分：增长证据 30%、岗位价值 25%、可讲解性 20%、完成度 15%、风险 10%。风险越高得分越低。
5. 排除 `generated-history.md` 中已发布或已生成的范围，选综合价值最高者。

## 单个仓库核验

至少读取仓库首页与 README、实际 `SKILL.md`、安装/使用说明、LICENSE，以及关键脚本或依赖清单的风险表面；不执行候选代码。

记录仓库、Skill 路径、核验日期、当前 Star、增长来源及时间窗、功能、输入、输出、安装命令、依赖、网络/令牌/权限、许可证、适用岗位和限制。

## 事实表达

- 当前数据、版本、安装命令、排行榜和公司信息必须附来源与核验日期。
- 项目文档声称但未实际验证的能力使用“项目说明显示”或“仓库提供”。
- 不把 Star、Fork 或榜单排名写成安全、质量或商业价值的证明。
- 安装命令逐字符引用可信文档。`curl | sh`、远程下载、令牌、付费 API、数据上传和高权限必须醒目标注。
- 来源可疑、冒名、无可解释用途或风险无法说明的候选不推荐。
