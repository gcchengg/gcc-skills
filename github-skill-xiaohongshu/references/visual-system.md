# 击凸 × 压凹技术解剖视觉系统

## 固定目标

生成 6 张 3:4 竖版中文 PNG。整体像艺术画册、设计书封和独立杂志，而不是办公信息图。真实厚纸、纸纤维、自然毛边、柔和侧光、清晰但细腻的 emboss/deboss 是共同材质。

同一期先确定一个视觉种子并贯穿 6 张：纸张、1–2 个主色与少量点色、光向、字号体系、线条、编号位置和工艺深度。先生成封面；02–06 使用封面作为直接视觉参考。

## 每期合理变化

从每组选择一种或混合两种，记录在 `视觉方案.md`：

- 字体：现代无衬线、优雅衬线、压缩体、细长体、高对比标题字、几何体、编辑体。
- 构图：偏左/偏右留白、上下轻重、对角线、角落、中心偏移、分区、模块、边缘、跨版。
- 标题：拆行、错位、跨区、局部竖排、横竖混排、断行、拉开字距、局部重叠、沿边、嵌入图形、与留白借位。
- 色彩：纯色、双色、同色深浅、低饱和双色、高对比双色；总主色不超过 2 种。
- 工艺：文字击凸/图形压凹，或反向；允许同色元素只靠纸面起伏出现。

## 产业链解剖语法

- 输入层：用户任务、文件、代码库或数据。
- 指令层：`SKILL.md` 中的判断与步骤。
- 执行层：模型、工具、脚本和外部依赖。
- 校验层：检查、失败条件、风险和权限。
- 输出层：可交付文件或业务结果。
- 价值流：时间、信息或判断如何经 Skill 变成可复用产物。

每张只保留 1 个主隐喻，可配 1–2 个辅助元素。标签贴近结构边缘；依赖箭头、风险环、成本热点和局部放大只在有事实依据时使用。

## 六张图的职责

1. 封面：Skill 名称、一句话价值、一个视觉隐喻。
2. Skill 是什么：定义、输入、输出、相邻工具区别。
3. 能力解剖：3–6 个能力层、依赖、边界或风险。
4. 工作流程：3–6 步，突出校验和失败处理。
5. 使用示例：一个准确场景，输入与结果可见。
6. 适合谁：3–5 个工作症状，岗位只是补充。

## 图像生成与 QA

每张最终提示词先写入 `prompts/01-...md` 至 `prompts/06-...md`，再调用内置 Image 2。提示词写出准确中文、画面职责、构图、材质、色彩、工艺、层级、禁止项和 3:4 竖版。

逐张检查中文、英文专名、命令和序号；主标题须在手机缩略图可读；节点和箭头符合事实；同一期风格一致但构图不机械复刻。禁止塑料、金属雕刻、夸张 3D、霓虹、复杂渐变、logo 墙、卡通、办公模板、水印和伪中文。

错字或结构错误必须重生成；禁止在生成图上用程序覆盖或重画文字。
