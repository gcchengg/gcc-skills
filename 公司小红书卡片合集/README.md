# 公司小红书卡片合集

本文件夹汇总目前已生成的所有公司小红书卡片。每家公司一个独立子文件夹，子文件夹内通常包含：

- `index.html`：卡片源文件
- `export-cards.js`：导出脚本
- `png/01.png` 至 `png/09.png`：9 张正式小红书卡片
- `png/00-overview.png`：9 张卡片总览图
- `小红书发布文案.md`：每家公司对应的标题备选、正文、话题标签和发布备注
