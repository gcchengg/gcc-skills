02 / 09

我看它，不是因为它“造存储颗粒”

华天科技的看点，是它处在集成电路封装测试环节：晶圆出来以后，芯片能不能稳定封起来、测出来、交出去。

它不是 DRAM 颗粒厂长鑫更偏 DRAM 制造，华天更偏封装测试、晶圆级封装和功能测试。
它卡在制造后段芯片设计和晶圆制造之后，还要封装、测试、验证，才能进入终端系统。
它有先进封装线索公司产品技术覆盖 SiP、Fanout、FC、WLP、MEMS、Memory 等封测方向。
我复盘的是方法赚钱不是重点，重点是从一个股票延伸出一条更完整的产业链观察路径。
投资笔记不是结论先讲认知，再讲公司

03 / 09

华天科技不是造颗粒，它更像“芯片后段交付平台”

把客户的晶圆和裸 die，变成可安装、可测试、可交付的芯片产品。

理解它，不是先看“存储概念”，而是先看封装路线、测试能力、良率和客户结构。

Packaging Test WLP / SiP
Design封装设计和仿真，提前处理互连、散热、可靠性和成本约束
WLP晶圆级封装和晶圆测试，让后段工艺更贴近晶圆制造
SiP系统级封装适合多芯片、小型化和模块化终端需求
Memory存储相关封测是它理解国产存储链条时的重要观察位置

和长鑫的区别
04 / 09

长鑫看 DRAM 制造，华天看封装测试后段

这条线要讲清楚：华天科技不是长鑫，也不是江波龙那种存储品牌和模组方案角色。它更适合放在“封装测试 + 晶圆级封装 + 可靠性交付”的位置理解。

长鑫更偏 DRAM 主线：内存颗粒、晶圆制造、国产替代的前台主角。
关注逻辑：国产存储不是只有颗粒，还包括封装、测试、散热、互连和终端可靠性。
华天更偏封装测试、晶圆级封装和多品类芯片后段交付，是产业链后段观察对象。
不要把角色混为一谈DRAM 制造 / 封装测试

商业模式
06 / 09

它赚的不是芯片设计的钱，而是封测工艺和交付能力的钱

华天科技的生意更像：承接客户晶圆，完成封装设计、封装制造、晶圆测试和成品测试，再跟随终端需求周期波动。

Design
封装设计和仿真决定互连、散热、结构强度和后续量产难度。
Package
封装路线决定尺寸、成本、性能边界和可靠性表现。
Test
晶圆测试和成品测试筛出良品，复杂芯片越多，测试价值越高。
Cycle
封测厂最终还是受产能利用率、下游景气、客户订单和资本开支影响。

08 / 09

但它不是“稳赚故事”

越是好讲的国产替代故事，越要把风险写在前面。观察池不等于买入点。

1
半导体景气有周期封测需求跟随消费电子、通信、汽车、存储等下游景气波动。
2
先进封装投入重设备、厂房、工艺开发和客户认证都需要资金与时间。
3
产品结构影响利润不同封装路线、客户结构和产能利用率，会直接影响盈利弹性。
4
不能只靠概念买股票还要看收入结构、毛利率、现金流、资本开支和技术升级进展。
