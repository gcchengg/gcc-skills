# WeChat Browser Publisher

## Overview

Use this skill to create a WeChat Official Account draft through the browser UI at `mp.weixin.qq.com` using an already logged-in Chrome/Edge session. Prefer saving a draft; do not mass-send or publish unless the user explicitly asks and the final browser state is visibly confirmed.

This skill is for browser publishing, not API publishing. If API sync fails with IP whitelist errors such as `40164 invalid ip`, this skill is the fallback.

## Workflow

1. Prepare a WeChat-ready article file.
   - Accept `.html` generated by `md2wechat convert` or `.md` that can be converted first.
   - Prefer HTML with inline styles for the WeChat editor.
   - Ensure local images exist. For fragile editors, upload/insert images manually or let the script attempt file chooser uploads.

2. Confirm browser access.
   - Use a real Chrome/Edge profile where the user is already logged into the WeChat Official Account backend.
   - If no CDP browser is running, launch Chrome manually with remote debugging, or use Codex/browser tooling if available.
   - If QR login, account selection, 2FA, or admin confirmation appears, pause and ask the user to complete it.

3. Run the automation script.
   - First use `--mode fill` when testing a new WeChat editor layout.
   - Use `--mode draft` to attempt saving a draft.
   - Never click final publish/mass-send automatically unless the user explicitly requested final publish in the current turn.

4. Verify result.
   - Inspect the editor visually: title, author, body, images, cover, digest, original declaration, comments.
   - If original declaration cannot be reliably verified, pause before final save/publish and ask the user to confirm manually.

## Script

Use `scripts/publish_wechat_browser.mjs`.

Typical command:

```bash
node /Users/apple/.codex/skills/wechat-browser-publisher/scripts/publish_wechat_browser.mjs \
  --html /path/to/article.wechat.html \
  --title "文章标题" \
  --author "作者" \
  --cover /path/to/cover.png \
  --mode draft
```

Options:

- `--html`: required, local HTML file to paste into the WeChat editor.
- `--title`: required unless the script can infer it.
- `--author`: optional.
- `--digest`: optional.
- `--cover`: optional local cover image.
- `--cdp`: Chrome DevTools endpoint, default `http://127.0.0.1:9222`.
- `--mode`: `fill`, `draft`, or `publish`. Default `draft`. Use `publish` only with explicit user approval.

## Browser Notes

Read `references/browser_publish.md` when:

- The CDP connection fails.
- The WeChat backend layout changes.
- Login, QR confirmation, original declaration, cover upload, or image insertion needs manual handling.
- The script fills text but images or styles do not carry over.

## Safety Rules

- Do not expose or request AppSecret in chat; this skill does not need API secrets.
- Do not claim publication succeeded unless the browser completed the save/publish and the resulting page confirms it.
- Default to creating a draft. Final publish/mass-send requires explicit user request and final UI confirmation.
- If a selector is uncertain, stop and report the visible page state rather than clicking destructive controls.
