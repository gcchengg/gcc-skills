# 正文

新品发布最怕的不是销售没话说，而是销售、客服、市场各说一套，遇到异议还临场编答案。

sales-enablement-kit 是一套内部销售赋能 Skill。它从 message house、PR-FAQ、定位与已批准 claims 出发，派生可用话术，不会凭空创造产品事实。

它会产出：
• 每个具名竞品一张 battle card
• 销售开场、发现问题、价值支柱与证据
• 异议→回应→证据指针表
• 内部 FAQ 与统一客服话术
• 谁在何时能说什么的发布通知

战卡不只写“我们赢”：还要诚实写对方赢在哪里，并提供能显出差异的探查问题。每条事实标记 Measured、User-provided 或 Estimated；没有来源就写 [needs source]。

最小用法：安装后说“基于这份 PR-FAQ，为产品 A 对比竞品 B 做销售战卡和异议表；禁止新增事实”。预期得到可追溯的战卡、回应和证据位置。

安装：npx skills add aaron-he-zhu/aaron-marketing-skills -s sales-enablement-kit

适合你，如果销售总在群里问最新版说法、异议回答靠个人经验、客服与销售口径不一，或发布前才临时做战卡。销售负责人、产品营销、客服运营和发布经理都能用。

注意：它不替你做持续竞品调研，也不发送外联。定价、日期、禁运信息缺失时必须阻塞，输出不保证成交。
