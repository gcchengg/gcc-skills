别再只说“润色一下”了
“帮我润色一下”最大的问题，是没人知道到底按什么标准改。语气、标题、代码示例和数字格式往往各改各的。

writing-guidelines 是 Vercel 的文档/文案审计 Skill。它每次先获取最新写作手册，再对指定文件执行 80+ 条规则检查。

它会检查：
①内容类型、目标读者与标题结构
②主动语态、直接称呼，以及 easy/simple/quick 等模糊词
③列表、代码语言、占位符、数字与单位
④定价页细节、AI 使用披露与 Review 责任
⑤按精简 file:line 格式交付问题

最小案例：输入 docs/quickstart.md，它检查标题是否面向用户、是否滥用“easy”、代码块有无语言、“64KB”是否应写成“64 KB”，再输出类似 quickstart.md:12 的定位结果。

安装：npx skills add vercel-labs/agent-skills

如果你的文档多人共编却口径不一、Review 只留“不够清晰”、同类格式错误反复出现，它适合技术写作、开发者关系、产品和内容团队。但它不替代事实核查、领域审稿和真实读者测试。
