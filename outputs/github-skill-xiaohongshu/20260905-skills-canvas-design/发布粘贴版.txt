做海报，先别急着堆元素

海报越改越满，却说不清它想表达什么？今天拆解非开发类 Skill：canvas-design。

它来自 anthropics/skills。项目说明显示，它先把主题转成一份设计理念，再用空间、色彩、构图和少量文字做静态作品。交付是设计理念 Markdown，以及 PNG 或 PDF，不是现成模板库，也不是名叫 Canvas 的在线设计软件。

它怎么做？
① 用4–6段说明视觉方向：形态、空间、色彩、尺度、节奏与层级。
② 从需求中提炼概念线索，让画面表达主题，而非堆砌说明文字。
③ 参考配套字体资源，安排图形与必要文字。
④ 再精修一轮，检查留白、重叠与边界；需要多页时延续语言但变化构图。

比如这样提需求（虚构示例，非实测）：
“用 canvas-design 做一张读书会概念海报，主题《留白之间》，安静、有呼吸感，只保留主题文字。先写设计理念，再输出 PNG。”
预期是理念文件＋概念海报；不是含日期、地点的发布成稿。

仓库给出的 Claude Code 安装命令：
/plugin marketplace add anthropics/skills
/plugin install example-skills@anthropic-agent-skills
这是整组示例技能，不只这一款；本次未安装。

边界：作品生成与导出依赖宿主能力，不能保证一次出稿；不是可编辑源文件或印刷交付保证。下载字体前核对来源与许可，中文需检查缺字；商业活动的日期、地点、品牌要求应另行明确。不要照搬他人作品。

如果你常常只有“高级感”三个字、设计越改越拥挤、系列海报每张像不同项目，它值得了解。适合内容、市场、活动策划与设计探索；不适合长文排版或期待免审核直接印刷的人。
