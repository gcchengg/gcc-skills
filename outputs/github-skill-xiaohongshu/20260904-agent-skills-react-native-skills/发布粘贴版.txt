RN卡顿？装这个Skill
写 React Native 最怕什么？列表一长就掉帧、动画拖沓、安全区和键盘问题反复返工。

Vercel 的 vercel-react-native-skills，是一套给 AI 编码代理使用的 React Native / Expo 最佳实践。它不是一句万能 Prompt，而是把规则按优先级拆成可查阅的文件，每条都有原因、反例、正例和参考。

它重点管这些事：
• 长列表虚拟化、稳定回调与轻量 item
• 动画只动 transform / opacity，配合 Reanimated
• 原生导航、Pressable、安全区与滚动 inset
• expo-image、状态最小化、Monorepo 原生依赖

最小用法：安装后让代理“按 vercel-react-native-skills 审查这个商品流页面，先找 CRITICAL/HIGH 问题，再给最小修改方案”。预期得到按优先级排列、能落到代码的建议。

安装：npx skills add vercel-labs/agent-skills

适合你，如果你经常遇到：列表滑动发涩、动画改完更卡、iOS/Android 行为不一致，或团队 review 总在重复提醒同类问题。前端、RN/Expo 开发和移动端技术负责人都能用。

注意：它是规范库，不替代真机 profiling；引入 FlashList、expo-image、Reanimated 等依赖前仍要核对版本。仓库 README 还保留旧名 react-native-guidelines，真实目录已是 react-native-skills。
