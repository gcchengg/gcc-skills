## 事实摘要

- 面向 React Native / Expo，覆盖列表、动画、导航、UI、状态、渲染、Monorepo 和配置。
- 列表性能为最高优先级；建议虚拟化长列表、稳定引用、轻量 item、优化列表图片。
- 动画建议优先 transform / opacity，并使用 Reanimated 派生值与手势系统。
- UI 建议包括 expo-image、Pressable、安全区、原生菜单/弹窗和 onLayout。
- 单条规则文件包含原因、错误示例、正确示例及参考；完整汇编见 AGENTS.md。
