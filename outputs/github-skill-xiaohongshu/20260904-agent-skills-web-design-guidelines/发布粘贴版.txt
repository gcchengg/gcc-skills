UI看着没问题？这Skill查100条
UI “看起来没问题”，不代表键盘能用、焦点可见、表单有错误反馈，也不代表动画尊重减少动效设置。

web-design-guidelines 是 Vercel 的 UI 代码审计 Skill。它不是生成一张“更好看”的图，而是对指定文件执行 100+ 条 Web 界面规则检查。

怎么工作？
①每次审计前获取最新规范
②读取你给的 UI 文件或 pattern
③检查无障碍、焦点、表单、动画、字体、图片、性能、导航、主题、触摸和国际化
④用精简 file:line 格式交付问题

最小案例：输入 src/components/Modal.tsx，它检查按钮命名、键盘操作、焦点可见性和动效降级，输出类似 Modal.tsx:42 的定位结果。

安装：npx skills add vercel-labs/agent-skills

如果你的 Review 总停在“感觉不对”、无障碍问题上线后才暴露、同类 UI 错误反复出现，它适合前端、设计系统和 QA 团队。但它需要联网获取规范，也不替代浏览器、辅助技术和真实用户测试。
