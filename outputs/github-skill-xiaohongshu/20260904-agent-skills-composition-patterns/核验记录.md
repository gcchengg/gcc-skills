## 功能、输入与输出

- 输入：React 组件代码、组件 API 或架构审查任务。
- 机制：按优先级读取独立规则；每条规则包含原因、错误示例、正确示例与参考。
- 输出：组件架构问题清单与可落地的重构建议。
- 核心规则：避免布尔属性膨胀；使用复合组件；提升状态；用通用 context 接口解耦状态实现；用显式变体组件替代模式开关；优先 children 组合。

## 边界与风险

- 它是编码规则知识库，不会自动证明重构后的 API 更好；仍需测试行为、可访问性和迁移影响。
- React 19 条目仅适用于 React 19+；React 18 或更早版本应跳过。
- “组合优于布尔属性”不是机械禁令；简单、稳定的二元状态不必为了形式强行拆组件。
