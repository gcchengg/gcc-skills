# 正文

一个 Button 同时塞进 isPrimary、isDanger、isLoading、hasIcon……能跑，但每加一个开关，组合状态和维护成本都在涨。

Vercel 的 vercel-composition-patterns，是给 AI 编码代理使用的 React 组件架构规则库。它会把组件代码按优先级审查，再用反例、正例和参考指导重构，不是只说一句“多用 composition”。

它重点解决：
• 用复合组件替代布尔属性膨胀
• 用显式变体组件表达不同模式
• 把状态提升到 Provider，方便兄弟组件共享
• 用 state / actions / meta 接口解耦状态实现
• 优先 children 组合，减少 renderX 属性

最小用法：安装后让代理“按 vercel-composition-patterns 审查这个 Modal API，找出布尔属性膨胀，并给兼容旧调用的迁移方案”。预期得到按 HIGH/MEDIUM 排序的问题与代码级改法。

安装：npx skills add vercel-labs/agent-skills

适合你，如果组件调用像开关面板、同一状态在多层 props 间搬运、每加一个变体都要改核心组件，或团队总在 review 争论 API。React 开发、组件库维护者和前端架构负责人尤其适用。

注意：React 19 规则仅用于 React 19+；简单二元状态不必强行拆分。它也不替代测试、可访问性检查和迁移评估。
