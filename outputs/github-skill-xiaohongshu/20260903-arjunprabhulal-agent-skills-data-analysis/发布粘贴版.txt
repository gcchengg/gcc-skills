AI算出的数字，先别急着信

AI 很快就能给你一个增长率，但这个数字可能精确地错了。

今天拆 data-analysis：一个把“先验证、再分析”写进流程的 Agent Skill。它先要求说清指标、统计人群、时间范围、对照基线，以及这个分析要支持什么决策。

接着才检查数据：时间断层、缺失值、重复行、测试账号、分布突变和时区。因为“当天没有订单”可能不是业务归零，而是数据管道断了；一次 Join 也可能把同一用户重复计算。

它还要求比较同类周期、考虑星期与节假日、观察分母变化，并先分群再下结论。整体平稳，可能掩盖一个人群上涨、另一个人群下跌。

最后输出不只是一句话。它要同时保存查询和参数，写明数据日期、排除项、分群结果，以及数据不能证明什么。相关不等于因果，小样本翻倍也未必值得庆祝。

例如“注册量周环比上涨 18%”，还要说明：排除了多少内部账号、是否存在重复批次、增长集中在哪个端，以及产品发布是否真的造成增长仍未证实。

安装：npx skills add arjunprabhulal/agent-skills，再选择 data-analysis。

谁需要它？如果你经常被追问“这个数字怎么算的”、不同报表口径打架、分析结论无法复现，或团队容易把相关性写成因果，它很值得用。适合数据分析师、产品经理、运营、增长和管理者。

注意：Skill 能约束分析步骤，但不能替代可靠数据源、业务判断和隐私权限控制。
