## 发布正文

React 页面慢，很多人第一反应是到处加 memo。但真正的问题，可能是串行请求、包过大、服务端重复工作或无效重渲染。

vercel-react-best-practices 是 Vercel Engineering 维护的 Agent Skill：用 70 条规则帮 Agent 编写、评审和重构 React/Next.js 代码。

它的关键不是“规则多”，而是先排优先级：
① Critical：消除请求瀑布、缩小包体积
② High：服务端缓存、并行请求、减少序列化
③ Medium：客户端请求、重渲染与渲染性能
④ Low：JavaScript 微优化与高级模式

SKILL.md 先做规则索引，再按需读取单条文件；每条都有原因、错误示例和正确示例。

最小案例：发现两个互不依赖的 await 顺序执行，它会匹配 async-parallel，建议用 Promise.all() 并行。

安装：npx skills add vercel-labs/agent-skills

如果你经常靠猜测优化、Review 没有统一标准、性能问题反复回归，它适合前端工程师和团队负责人。但它不代替 profiler、真实用户指标和回归测试；规则也要结合 React/Next.js 版本判断。
