# 05 使用示例

延续同一期纸张、色彩、字体、光线和击凸压凹。3:4 竖版，跨版构图。主视觉是一张左侧压凹的“产品发布 Brief”，穿过中央森林绿编辑手册后，在右侧展开为五张错位纸片；一进多出，关系清晰，非普通办公信息图。

准确呈现：
标题“一份 Brief，变成一组内容”
左侧输入卡：
“新品发布 Brief”
“目标：获得试用”
“受众：运营负责人”
中间“content-marketing”
右侧五项：
“主题文章”
“落地页文案”
“演示视频脚本”
“Newsletter”
“高管署名稿”
底部“统一检查：品牌语气 / 事实 / CTA / 渠道格式”
右下编号“05”

标题与输出纸片击凸，输入和路径压凹，橙红标出审核点。禁止照片、人物、logo、复杂图标、渐变、塑料、金属、水印、伪中文。文字精确易读。
