# 01 封面

生成一张 3:4 竖版中文小红书封面，艺术书封与独立杂志气质。暖米白厚棉纸，真实纸纤维、轻微自然毛边，左上柔和侧光。森林绿为主色，少量橙红点睛。中心偏移构图，大面积留白。主视觉只有一本森林绿击凸的“编辑手册”，七枚小型压凹圆片围绕并由极细压痕连接，象征一个 Skill 统筹七位内容专家。

必须准确呈现文字：
主标题“一个 Skill”
第二行“带着 7 个内容专家”
小字“CONTENT MARKETING”
副句“不是 Prompt 合集，是一间 AI 编辑部”
右下编号“01”

高对比衬线中文大标题与压缩无衬线英文混排，三级字号，部分标题击凸，图形压凹。安静、现代、克制、聪明。禁止卡通人物、logo、复杂插画、渐变、塑料、金属、夸张 3D、水印、伪中文。所有文字逐字准确、手机缩略图可读。
