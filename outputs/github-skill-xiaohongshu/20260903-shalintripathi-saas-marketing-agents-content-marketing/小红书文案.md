# 正文

写博客、案例、白皮书、视频脚本，每次都要重新给 AI 讲品牌、受众和目标？

今天拆的是 `content-marketing`：一个面向 B2B SaaS 的内容编排 Skill。它不是七条零散 Prompt，而是把任务路由给 7 个内容角色：博客策略、案例研究、白皮书、转化文案、视频脚本、Newsletter 和高管思想领导力。

它最重要的第一步，是读取 `brand-context.md`：ICP、定位、信息支柱、品牌语气、禁用词和可引用证据。没有客户名、指标、认证或成果依据时，必须标成待补充，不能让 AI 猜。

工作流分 5 段：明确目标与受众 → 研究和大纲 → 初稿 → 反馈修订 → 按渠道优化交付。不同角色还能交接：一份白皮书可继续变成视频脚本、Newsletter 和落地页文案。

比如发布一个 SaaS 新功能：先确定定位，再产出主题文章、演示脚本、邮件内容和高管署名稿，最后统一检查品牌语气、事实、CTA 与渠道格式。

安装：先执行 `/plugin marketplace add shalintripathi/saas-marketing-agents`，再执行 `/plugin install saas-marketing@saas-marketing-agents`。

谁需要它？如果你总在重复写 Brief、多人内容口径不一致、一份素材难以复用、审核时才发现事实没依据，它更有价值。适合 B2B 内容负责人、品牌营销、产品营销和小型 SaaS 团队。

注意：仓库当前热度不高；它提供的是工作方法，不等于无需人工审核。涉及客户数据、案例指标和发布权限时仍要谨慎。

Prompt 写一篇，Skill 管一条内容生产线。
