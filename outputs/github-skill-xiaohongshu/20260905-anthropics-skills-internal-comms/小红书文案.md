# 正文

周报写了很多，同事还是问“所以现在卡在哪里”？

今天换一个非开发类 Skill：internal-comms，来自 anthropics/skills。项目提供内部沟通写作规范：先识别周报、公司简报、FAQ 等任务，再读取对应示例文件，按各自格式组织材料。

周报走 3P：Progress 写进展，Plans 写下一步，Problems 写阻碍，每部分1–3句话。公司简报关注全公司相关信息；FAQ 尽量引用权威口径，不确定就标明。

试着说：用 internal-comms，把活动运营组本周材料写成3P周报。本周完成场地确认；下周上线报名页；主视觉待审批，影响物料制作。预期得到三段草稿，不是自动核验过的事实。这里是虚构演示。

它的价值不是“文笔更华丽”，而是把读者、信息类型和格式分开处理。

仓库提供的 Claude Code 安装方式：
/plugin marketplace add anthropics/skills
/plugin install example-skills@anthropic-agent-skills
注意：安装的是示例技能合集，不是仅此一项；本次未安装。

如果你总把进展与计划混写，或跨部门问答口径不一致，可了解它。适合运营、行政、人事与团队负责人。

周报可使用你粘贴的材料；接入聊天、邮件和文档需另行授权。公司数据先脱敏，发送前复核，不能代替官方审批。
