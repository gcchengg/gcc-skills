# 正文

普通会议摘要最容易丢掉的，不是结论，而是为什么这么决定、谁负责、什么时候交付。

meeting-transcript-summary 是一套会议逐字稿处理 Skill。它支持 Meet、Zoom、Teams、VTT、SRT 和纯文本，把同一份记录拆成不同阅读层级，而不是压成几条空泛 bullet。

它会交付：
• 高管摘要：目标、决策、影响、风险
• 按主题整理的详细讨论与决策理由
• 行动项表：事项、负责人、截止日、验收标准
• 严格五句摘要，方便发群或写周报
• 可选 Canvas 看板与知识图

最小用法：提供逐字稿后说“用 meeting-transcript-summary 处理；只保留明确说出的事实，缺少负责人或日期就标记未指定”。预期得到三层摘要与可追踪行动项。

获取：git clone https://github.com/terravic/meeting-transcript-summary-skill.git

适合你，如果会后总在翻聊天记录、行动项没人认领、纪要只有结论没有理由，或同一场会要分别汇报给老板和执行团队。项目经理、运营、咨询、销售和管理者都能用。

注意：仓库目前 0 star，不代表效果已被广泛验证。转写和说话人识别错误会污染结果；逐字稿可能含机密与个人信息，上传前先确认权限，关键决策必须人工复核。
