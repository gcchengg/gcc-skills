汇报风格别再东拼西凑

内容已经写好，配色和字体却越改越乱？

今天这个非开发类 Skill 叫 theme-factory，来自 anthropics/skills。项目提供10套主题，每套有明确色值和标题、正文字体搭配，让整份材料遵循同一套视觉规则。

它不是一套固定版式模板，也不是让 AI 随便“美化一下”。工作流程是：看主题样张→选择→明确确认→读取主题规范→应用并检查对比度与可读性。没有合适的预设，也可以生成新主题，审阅后再用。

示意调用：用 theme-factory，为已有婚礼策划方案展示主题，让我确认后再应用。若选 Desert Rose，项目规范采用柔和玫瑰色与大地色系，标题用 FreeSans Bold，正文用 FreeSans。中文覆盖与实际排版仍需检查；这不是软件实测。

仓库给出的 Claude Code 安装入口：
/plugin marketplace add anthropics/skills
/plugin install example-skills@anthropic-agent-skills
这是示例技能合集，不是只安装 theme-factory。本次未安装。

如果你的材料每页像不同模板，或标题与正文字体不断变化，可以了解它。适合策划、运营、培训和品牌人员。

边界：它主要管颜色与字体，不替你修复内容逻辑，也不保证一键导出成品。需要兼容宿主和文档编辑能力；使用前备份，导出后检查字体、溢出与品牌要求。
