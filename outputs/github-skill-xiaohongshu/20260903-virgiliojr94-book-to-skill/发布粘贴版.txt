读完的书，终于能变成Skill

收藏很多专业书，真正工作时却想不起该用哪一章？

book-to-skill 不是“AI帮你总结一本书”，而是把 PDF、EPUB、DOCX、Markdown、网页或资料文件夹，转换成能被 AI Agent 按需调用的结构化 Skill。

它会提取书里的框架、原则、执行步骤、反模式、边界和专有术语，再生成 SKILL.md、章节资料、术语表与速查内容。重点是保留“方法如何使用”，而不是压缩成读书笔记。

它由两部分组成：Python 提取器负责清洗文档和元数据；生成规范负责识别知识结构并拆分章节。以后遇到任务，Agent 只加载相关规则，不必反复读取整本书。

例如，把 60 页品牌手册做成 brand-guide Skill，AI 就能按同一套语气、禁用词、视觉原则和审核清单写文案、查页面。

安装：npx skills add virgiliojr94/book-to-skill

谁需要它？

• 总在重复查同一份规范
• 每次都要向 AI 重讲背景
• 想把个人方法论长期复用
• 团队文档很多，却缺少可执行规则

适合研究人员、教师、产品经理、设计师、开发者、顾问和知识管理人员。偶尔总结短文的人直接让 AI 阅读更省事。

注意：项目方测试报告中的 token 节省数据不代表所有资料；版权内容应保持私有，分享前检查授权。

Prompt 解决一次问题，Skill 复用一套知识。
