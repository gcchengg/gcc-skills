# 视觉方案

- 比例：3:4 竖版，6 张连续知识卡。
- 纸张：暖灰白色厚棉纸，细密纤维、自然毛边、真实厚度。
- 配色：墨黑绿 `#173B35` + 焦糖橙 `#C85B32`，背景暖灰白 `#EEE8DC`。
- 字体：高对比编辑衬线体 + 压缩无衬线体；主标题大字，中层说明，微型编号。
- 构图：封面偏左留白；内页使用左右分区、爆炸剖面、纵向路径、中心偏移与角落构图。
- 主隐喻：一本书沿书脊被压开，内容变成可拆卸的 Skill 模块。
- 工艺：标题局部击凸，结构、路径和页框压凹；焦糖橙只用于价值流和关键节点。
- 共同元素：右边缘竖排 `GITHUB SKILL 002`、细线、圆点、页码；同一右上侧光。
- 禁止：塑料、金属雕刻、霓虹、复杂渐变、办公模板、密集小字、伪中文、水印。
