# 正文

每页都好看，放在一起却不像一套？今天拆解一个非开发类 Skill：brand-guidelines。

它来自 anthropics/skills。项目说明显示，它把 Anthropic 的配色、标题字体、正文字体和形状强调色写成可复用规则。输入是需要统一视觉的材料，输出是按这些规则处理的版本；不是自动识别任意品牌的工具。

它管什么？
① 深浅背景与文字的搭配。
② 标题用 Poppins，正文用 Lora。
③ 缺字体时回退到 Arial／Georgia。
④ 给非文字形状分配强调色，保留层级。

和一句“帮我美化”相比，关键是具体规则；它也不是包含多个主题的主题库。

试着这样提需求（示例，非实测）：
“用 brand-guidelines 统一这份英文活动提案，保留内容与结构，列出字体替换。”
预期是统一后的材料；文件编辑与导出仍依赖宿主工具。

仓库给出的 Claude Code 安装方式：
/plugin marketplace add anthropics/skills
/plugin install example-skills@anthropic-agent-skills
注意：安装的是整组示例技能，不只这一个；本次未安装。

边界：内置规范属于 Anthropic，自有品牌需另配规范；中文字体需单独确认，导出后检查缺字与换行。配色相近不代表官方背书。

如果你总在复制旧页后改色、合并材料时统一字体、交付前修层级，它值得了解。适合品牌、市场、行政和内容工作；不适合期待自动生成完整品牌战略的人。
