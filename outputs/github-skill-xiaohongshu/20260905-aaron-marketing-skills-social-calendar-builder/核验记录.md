## 事实和风险

项目提供栏目配比、固定更新槽位、备稿队列、批次生产、常青内容复用与热点留白。配比是Estimated启发式，需设日期用自有数据校准，不是平台规则。排期不得超出制作和互动接待能力。仅规划日历；不写正文、不改编素材、不自动发帖或调度。完整运行读取渠道注册表、品牌声音、带日期规范与趋势判断，不能说零配置即用。

审核要求由social-quality-auditor处理成稿，只有SHIP才能进队列；FIX/BLOCK退回。日历本身不能自批。旧文复用时重查日期、价格、主张；热点skip则留空。

风险表面：README明确仓库有Bash/Python标准库hooks、验证、打分、registry和连接器。基本层用用户提供的数据；CONNECTORS.md描述可选凭据层。该Skill引用registry-events.py，通过授权提案记录新节奏，渠道注册表维护正式记录；保存结果/写记忆需要确认。趋势输入可能联网，自有平台数据可用用户导出，需脱敏。没运行脚本、没安装、没接入账号，也没发布。平台风控说法在文档中是项目边界，本稿不扩展为法律结论。

安装命令逐字引用README：`npx skills add aaron-he-zhu/aaron-marketing-skills`。这是仓库选择安装入口，不是只安装目标项的命令。安装依赖联网及宿主权限，宿主模型与可选服务可能收费。

咖啡店排期是原创虚构教学场景；周一/三/五非最佳时间建议，三篇上限是假设的用户产能，热点替换而不增加槽位。未声称真实效果。
