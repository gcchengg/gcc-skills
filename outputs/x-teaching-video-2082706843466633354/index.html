每周重复发同一套要求？你缺的可能不是提示词，而是 Skill
Skill 像岗位说明书、标准流程和验收清单
重复、稳定、有步骤、有标准，才值得沉淀
先写清启动条件、输入、步骤、输出、标准和异常处理
用点名、自然表达、信息不完整三类说法测试触发
最小版本只需要 SKILL.md，其余目录按需增加
description 决定何时触发，正文决定如何执行
结构校验以后，还要拿真实工作反复测试
把“每次都要重新解释”变成“它以后知道怎么做”
