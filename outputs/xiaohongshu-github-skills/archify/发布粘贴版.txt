架构师别再手动画图了！这个 Skill 火了

最近发现一个很适合架构师、开发者和技术产品经理的 Agent Skill：Archify。

它不是给 Mermaid 换皮，也不是让 AI 随便画一张“看起来像架构图”的图片。

Archify 的作用，是把代码库或一段系统描述，转换成可以校验、继续修改、交互查看和导出的系统地图。

它能生成 5 类常见技术图：

• 架构图：组件、服务、存储和系统边界
• 工作流图：参与者、顺序、分支和异常
• 时序图：调用方、返回值和交互时机
• 数据流图：来源、转换、存储和敏感边界
• 生命周期图：状态、事件、重试和最终结果

它和普通 AI 画图最大的区别，是中间增加了一套结构化和校验过程：

① Agent 先把系统整理成带类型的 JSON 结构
② 渲染器根据结构生成图，而不是自由发挥
③ 交付前检查结构、布局、路径和标签
④ 校验失败会指出具体问题，不覆盖上一个正确版本
⑤ 修改指定节点时，尽量保持其他结构稳定

所以它追求的不只是“图好看”，还要让节点和关系经得起检查。

举个例子，你可以直接说：

“画出浏览器访问 API 的过程。先查询 Redis；缓存未命中时，再回退到 PostgreSQL。”

Archify 会把这句话转换成有明确节点、主路径和回退路径的系统地图。

除了静态图片，它还能生成自包含 HTML，并支持 PNG、SVG、WebM 和分享卡导出。图中的节点可以搜索，也能查看上游、下游和指定路径。

安装：npx skills add tt-a1i/archify -g

不安装先试用：npx skills use tt-a1i/archify@archify --agent codex

什么样的人需要它？

• 每次开会都要重新解释系统结构
• 架构图改几次就和真实系统对不上
• 经常把代码和技术方案讲给非技术同事
• 评审前必须检查路径、边界和依赖关系
• 希望架构图可以持续维护，而不是画完就失效

对应岗位通常是：软件架构师、开发者、技术产品经理和解决方案顾问。

注意：它不是通用绘图软件，也不会自动证明线上系统一定按图运行。安装第三方 Skill 前，请检查源码、权限、依赖和网络行为。

AI 时代，真正值得沉淀的不是一句 Prompt，而是一整套可以反复执行、检查和改进的工作方法。
