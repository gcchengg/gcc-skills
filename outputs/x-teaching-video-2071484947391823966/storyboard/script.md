# 教学脚本

## 核心信息

Codex 的价值不只是写代码，而是成为知识工作的智能体工作台。

## 教学路线

1. 项目是容器，对话和目标在里面跑，插件扩展能力，站点输出成果。
2. 适合交给 Codex 的任务通常需要多来源信息、有重复步骤、可检查且有明确产出。
3. 所有稳定工作流都遵循：连接工具、写入上下文、执行、去真实场景审核、沉淀复用。
4. 工作空间至少要明确 context、preferences、rules 三类信息。
5. 从单次任务逐步升级到多来源、定期自动化、自建工具和持续学习系统。
6. 一份清单能验证的任务可以委派；每次都要重新判断的任务适合人机协作。
7. 从一个真实、低风险、可检查的任务开始。
